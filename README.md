## Задание 1. List

### Текст задания

Составить программу, которая удаляет из списка L все элементы E, если такие есть.

### Алгоритм решения

Создаётся список `List<int>`. Пользователь вводит количество элементов и сами элементы. Затем вводится значение E. Список проходится с конца, и все элементы, равные E, удаляются методом `RemoveAt`. После этого список выводится на экран.

### Тестирование

Программа корректно удаляет все вхождения заданного элемента. При отсутствии элемента список остаётся без изменений. Проверка ввода реализована через класс `Checked`.

## Задание 2. LinkedList

### Текст задания

Напечатать в обратном порядке элементы непустого списка L.

### Алгоритм решения

Создаётся двусвязный список `LinkedList<int>`. Элементы добавляются методом `AddLast`. Для вывода в обратном порядке используется свойство `Last` и переход по ссылке `Previous` до начала списка.

### Тестирование

Список успешно выводится в обратном порядке. Работает корректно при любом количестве элементов (больше 0).

## Задание 3. HashSet

### Текст задания

В городе имеется n общеобразовательных учебных заведений, которые могут закупать компьютерную технику. Есть перечень компьютерных фирм. Ответить на вопросы:
* в каких фирмах закупка производилась каждым из заведений;
* в каких фирмах закупка производилась хотя бы одним из заведений;
* в каких фирмах ни одно из заведений не закупало компьютеры.

### Алгоритм решения

Создаётся общий `HashSet` всех фирм. Для каждой школы создаётся свой `HashSet` выбранных фирм. Пересечение всех школьных множеств даёт фирмы, в которых закупались все школы. Объединение всех школьных множеств даёт фирмы, в которых закупалась хотя бы одна школа. Разность общего множества и объединения даёт фирмы, в которых никто не закупал.

### Тестирование

Программа правильно определяет три категории фирм. Есть проверка, что выбранная школой фирма существует в общем списке.

## Задание 4. HashSet

### Текст задания

Файл содержит текст на русском языке. Напечатать в алфавитном порядке все звонкие согласные буквы, которые входят хотя бы в одно слово.

### Алгоритм решения

Текст читается из файла `Files/lab4.txt`. Все символы приводятся к нижнему регистру. Проверяется вхождение в строку звонких согласных `"бвгджзйклмнр"`. Найденные буквы добавляются в `HashSet<char>` (автоматически убираются дубликаты). Затем множество преобразуется в список, сортируется и выводится.

### Тестирование

Программа корректно находит и выводит в алфавитном порядке только звонкие согласные, встречающиеся в тексте. Добавлена проверка существования файла.

## Задание 5. Dictionary

### Текст задания

На вход программы подаются фамилии и имена учеников (не более 100). Требуется сформировать уникальный логин для каждого ученика: если фамилия встречается первый раз — логин равен фамилии, при повторном появлении к фамилии добавляется порядковый номер (2, 3 и т.д.).

### Алгоритм решения

Отдельным методом `FillStudentsFile` данные записываются в файл `Files/students.txt` в формате `Фамилия;Имя`. При чтении файла используется `Dictionary<string, int>` для подсчёта количества появлений каждой фамилии. Логин формируется как фамилия или фамилия + номер.

### Тестирование

Логины формируются правильно. Реализована проверка длины фамилии (≤ 20) и имени (≤ 15), а также проверка, что строка состоит только из букв. Добавлена защита от отсутствия файла и некорректных строк.

## Задание 6. Класс Time + перегрузка оператора

### Текст задания

Создать класс `Time` с полями `byte hours` и `byte minutes`. Реализовать добавление произвольного количества минут (`uint`) к объекту типа `Time`. Результат должен быть типа `Time`. Переопределить метод `ToString()`.

### Алгоритм решения

Класс содержит закрытые поля `hours` и `minutes`. Конструктор проверяет корректность значений (0–23 и 0–59).

Перегружен оператор `+` (`Time + uint`). Общее количество минут переводится в диапазон 0–1439 с помощью `% 1440`, после чего вычисляются новые часы и минуты. Метод `ToString()` возвращает время в формате `ЧЧ:ММ`.

### Тестирование

Конструктор и оператор `+` работают корректно, в том числе при переходе через сутки. Ввод часов и минут проверяется на допустимый диапазон.
