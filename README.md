## Задание 1. List

### Текст задания

Составить программу, которая удаляет из списка L все элементы E, если такие есть.

### Алгоритм решения

Создаётся список `List<int>`. Пользователь вводит количество элементов и сами элементы. Затем вводится значение E. Список проходится с конца, и все элементы, равные E, удаляются методом `RemoveAt`. После этого список выводится на экран.

## Задание 3. HashSet

### Текст задания

В городе имеется n общеобразовательных учебных заведений, которые могут закупать компьютерную технику. Есть перечень компьютерных фирм. Ответить на вопросы:
* в каких фирмах закупка производилась каждым из заведений;
* в каких фирмах закупка производилась хотя бы одним из заведений;
* в каких фирмах ни одно из заведений не закупало компьютеры.

### Алгоритм решения

Создаётся общий `HashSet` всех фирм. Для каждой школы создаётся свой `HashSet` выбранных фирм. Пересечение всех школьных множеств даёт фирмы, в которых закупались все школы. Объединение всех школьных множеств даёт фирмы, в которых закупалась хотя бы одна школа. Разность общего множества и объединения даёт фирмы, в которых никто не закупал.

## Задание 6. Класс Time + перегрузка оператора

### Текст задания

Создать класс `Time` с полями `byte hours` и `byte minutes`. Реализовать добавление произвольного количества минут (`uint`) к объекту типа `Time`. Результат должен быть типа `Time`. Переопределить метод `ToString()`.

### Алгоритм решения

Класс содержит закрытые поля `hours` и `minutes`. Конструктор проверяет корректность значений (0–23 и 0–59).

Перегружен оператор `+` (`Time + uint`). Общее количество минут переводится в диапазон 0–1439 с помощью `% 1440`, после чего вычисляются новые часы и минуты. Метод `ToString()` возвращает время в формате `ЧЧ:ММ`.
